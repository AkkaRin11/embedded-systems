# Техническое задание на разработку автономного робота-бармена (BeerBot)

## 1. Требования к функциональным характеристикам

Робот должен выполнять следующий алгоритм действий:

### Взаимодействие с тарой
- Обеспечивать надежную установку банки с напитком (объемом 0.5 л) на платформу робота
- Обеспечивать герметичное подключение штатной трубки (шланга) от насоса к банке с напитком

### Автономное перемещение
- Осуществлять движение по ровной горизонтальной поверхности (столу) в автономном режиме
- Реализовать алгоритм случайного обхода поверхности для поиска цели с возможностью обхода препятствий
- *(На перспективу)* Иметь аппаратно-программный задел для реализации функции построения карты поверхности и навигации по ней

### Распознавание цели
- При помощи встроенной системы технического зрения осуществлять поиск стаканов на поверхности
- Опознавать целевой стакан по специальной маркировке (например, QR-код, ArUco-маркер, цветовой маячок)
- *Точный тип маркировки подлежит уточнению*

### Выполнение основной задачи
- При успешном обнаружении целевого стакана останавливаться в зоне досягаемости насоса
- Активировать насос для перекачивания заданной порции напитка (объем порции задается программно) из банки в стакан через подключенный шланг
- После завершения налива возобновлять движение для поиска следующего стакана

## 2. Требования к надежности

### Показатели надежности
- **Средняя наработка на отказ:** не менее 10 циклов (задача "поиск-налив") без вмешательства оператора

### Устойчивость к ошибкам
Робот должен корректно реагировать на следующие ситуации:
- Потеря целевой маркировки из поля зрения → возобновить поиск
- Столкновение с незначительным препятствием → отъехать и сменить направление
- Окончание напитка в банке → подавать сигнал оператору и переходить в режим ожидания
- Низкий заряд аккумулятора → подавать сигнал оператору

### Требования безопасности
- **Защита от протечек:** Конструкция узла подключения шланга к банке и система управления насосом должны исключать несанкционированную протечку напитка

## 3. Условия эксплуатации

### Рабочая среда
- **Рабочая поверхность:** ровная, горизонтальная, сухая
- **Материалы поверхности:** дерево, пластик (стол)

### Освещение
- **Освещенность:** стандартное комнатное освещение (искусственное или дневное)
- **Требование к системе зрения:** устойчивость к умеренным изменениям в освещенности

## 4. Требования к составу и параметрам технических средств

### Шасси
- **Тип платформы:** мобильная платформа с двумя ведущими колесами и одним/двумя опорными роликами / всенаправленные колёса

### Система управления
- **Основной контроллер:** Одноплатный микрокомпьютер (Raspberry Pi 5)

### Система навигации и датчики
- **Камера**
- **Дальномеры/датчики расстояния:** не менее 2-х (спереди и/или по бокам)
- **Типы датчиков:** ультразвуковые HC-SR04 или инфракрасные

### Система дозирования
- **Насос:** перистальтический (шланговый) насос
- **Емкость для напитка:** штатная банка 0.5 л

## 5. Требования к информационной и программной совместимости

### Операционная система
- Raspberry Pi OS (64-bit) Linux

### Программное обеспечение и библиотеки

#### Базовое ПО
- **Python 3.9+** - основной язык программирования
- **OpenCV 4.5+** - компьютерное зрение для распознавания маркеров
- **NumPy** - математические вычисления
- **Picamera2** - работа с камерой Raspberry Pi

#### Библиотеки для управления hardware
- **RPi.GPIO** - работа с GPIO пинами
- **Adafruit-MotorHAT** или **gpiozero** - управление моторами
- **PySerial** - работа с последовательными портами

#### Библиотеки для компьютерного зрения
- **ArUco** (входит в OpenCV) - распознавание маркеров
- **imutils** - вспомогательные функции обработки изображений
- **PyZbar** или **python-qrcode** - работа с QR-кодами

### Требования к интерфейсам
- **GPIO** - подключение датчиков и управления моторами
- **I2C** - подключение дополнительных сенсоров
- **USB** - подключение камеры и периферии

## 6. Требования к транспортированию и хранению

### Транспортировка
- **Состояние:** в выключенном состоянии
- **Упаковка:** штатная упаковка (бокс)
- **Защита:** от механических повреждений, вибрации и попадания влаги
- **Запрет:** транспортировка с установленной банкой с напитком

### Хранение
- **Условия:** сухое помещение при температуре от +5°C до +40°C
- **Шланги и уплотнители:** расслабленное состояние (без изгибов и напряжения)
